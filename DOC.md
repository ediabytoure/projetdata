Le jeu de données que j’ai choisi correspond aux Pétitions de l'Assemblée nationale, dans ce jeu de données ont retrouvé un tableau avec 4125 pétitions citoyennes déposées dans la plateforme et 11 colonnes qui contextualisent la pétition avec une description, le n° de votes, la date, la législature, etc. Ainsi que la décision de la commission vis-à-vis de la pétition.
Les défis que ce jeu de données nous pose est le manque de catégorisation des pétitions, les pétitions sont enregistrées par ordre chronologique et non par thèmes. On a également le nombre de votes qui est mis à jour quotidiennement donc le défi majeur serait de hiérarchiser ou catégoriser les pétitions pour mettre en valeur les sujets qui mobilisent le plus de participants. Ce jeu de données possède une grande complexité en partie à cause du vaste nombre de thématiques abordées mais également du fait que les données évouluent dans le temps, le statut d'une pétition est en constant changement. Certaines pertitions sont également soit très similaires soit des doublons ou des reformulations donc ça serait pas pertinent de les classer comme des pétitions séparées.
Pour nourrir un modèle il faudrait définir des variables pour mesurer la popularité d'une pétition, des variables pour identifier les thématiques d'une pétition ainsi qu'une variable pour mesurer l'ancienntée.
Source : https://www.data.gouv.fr/datasets/petitions-de-lassemblee-nationale
